# soundAr brand assets

Use SVG assets for interface, documentation, and print placements. The Tauri
launcher assets in `app/src-tauri/icons` are generated from
`soundar-app-icon.svg`.

| Asset | Intended use |
| --- | --- |
| `soundar-app-icon.svg` | Launcher, installer, favicon, and square avatar |
| `soundar-mark-dark.svg` | Symbol on dark backgrounds |
| `soundar-mark-light.svg` | Symbol on cream or light backgrounds |
| `soundar-mark-white.svg` | Plain white symbol on photography or solid color |
| `soundar-mark-black.svg` | Plain black symbol for one-color production |
| `soundar-lockup-dark.svg` | Symbol with wordmark on dark backgrounds |
| `soundar-lockup-light.svg` | Symbol with wordmark on cream or light backgrounds |
| `soundar-lockup-white.svg` | Plain white symbol and wordmark |

Keep clear space around the mark equal to the coral broadcast dot. Do not
recolor individual waveform strokes or compress the artwork non-proportionally.
